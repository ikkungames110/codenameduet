# コードネーム デュエット（P2P版）

2人協力の言葉当てボードゲーム「コードネーム デュエット」のルールをブラウザで再現したものです。
PeerJS（WebRTC）で端末同士を直接つなぎ、URLを送るだけで離れた相手と遊べます。

- 公開URL: https://codenameduet.pages.dev/

## ルール（実装済み）
- 5×5の単語カード、両面キーカード（各面 緑9・暗殺者3・一般人13、両面共通の緑3）
- 手がかり（1単語＋数 0〜9/∞）→ 相手が推理。緑なら継続、一般人でターン終了、暗殺者で即敗北
- 1枚以上選べば任意で終了／ターンごとにタイマー消費、手がかりを出す人は交代
- 自分の緑を全部見つけてもらった人は以後当てる役のみ
- タイマー切れでサドンデス（緑以外を選ぶと敗北）、15人全員発見で勝利
- タイマー数・許容ミス数は変更可能（標準 9/9）

## 開発
```sh
npm install
npm run dev
npm test
npm run build && npx wrangler pages deploy dist --project-name codenameduet --branch main
```
ホストの端末が進行役となり、ゲストには相手のキーカードを含まない情報だけを送ります。ホストはページを再読み込みしても同じ部屋に復帰できます。
